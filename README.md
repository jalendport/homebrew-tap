<h1 align="center">Homebrew Tap</h1>

This is the Homebrew tap for my command-line tools. Right now it serves one cask, [Maestro](https://github.com/jalendport/maestro), and anything else I ship as a binary will land here too.

## Installation

You're going to want to install by the full tap path rather than tapping first and installing by name, because the bare name `maestro` resolves to a different cask in Homebrew's main index (not mine):

```sh
brew install jalendport/tap/maestro
```

Upgrading works the same way, full path included:

```sh
brew upgrade --cask jalendport/tap/maestro
```

## How the casks are maintained

Every file under `Casks/` is generated by [GoReleaser](https://goreleaser.com) when a tool cuts a release, so the version, download URLs, and checksums are written by the release pipeline and never by hand. If something in a cask looks off, the fix lives in the tool's own release config, not in this repo.

## Support

Found a bug in one of the tools? Open an issue on that tool's repo (e.g. [Maestro issues](https://github.com/jalendport/maestro/issues)). Problems with the tap itself can go [here](https://github.com/jalendport/homebrew-tap/issues).
